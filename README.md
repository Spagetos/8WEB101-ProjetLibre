# 8WEB101-ProjetLibre
8WEB101-ProjetLibre

ZGames est une plateforme Web interactive qui regroupe plusieurs mini-jeux accessibles directement depuis un navigateur. Le site permettra aux utilisateurs de découvrir différents types de jeux, notamment des jeux d'arcade, de réflexion et de stratégie, à travers une interface intuitive et organisée. Chaque jeu sera présenté dans un catalogue permettant aux utilisateurs de sélectionner facilement celui auquel ils souhaitent jouer. L'objectif du projet est de développer une plateforme conviviale, offrant une expérience de jeu simple et accessible, tout en proposant une variété de divertissements au sein d'un même environnement numérique.


Technologie choisie :
- HTML, CSS, JavaScript
- Phaser "https://phaser.io/"
